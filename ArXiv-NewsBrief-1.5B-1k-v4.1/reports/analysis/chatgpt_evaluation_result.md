# 실험 평가 결과 로그
## 일반 사용자 대상 AI 논문 뉴스 브리핑

---

## 1. 실험 메타데이터

- **프로젝트명**: AI 논문 뉴스 브리핑 (일반 사용자)
- **타깃 사용자**: 비전문가 / 일반 대중
- **언어**: 한국어
- **목표 요약 길이**: 약 30초
- **출력 제약 조건**: 정확히 2문장 (강제)
- **평가 일자**: YYYY-MM-DD
- **평가 방식**: 자동 지표 + 사람 평가
- **비고**: 본 로그는 *점수 기록*이 아닌 *의사결정*을 목적으로 한다.

---

## 2. 모델 구성

### 2.1 베이스 모델

- **모델명**: Base Summarization Model
- **학습 방식**: 사전학습 모델 (태스크별 미세조정 없음)
- **프롬프트 스타일**: 자유 요약
- **문장 수 제약**: 없음

---

### 2.2 파인튜닝 모델

- **모델명**: Fine-tuned Model (SFT)
- **학습 방식**: 지도 미세조정(Supervised Fine-Tuning)
- **학습 데이터**: 과학 논문 요약 데이터(ArXiv 계열)
- **프롬프트 스타일**: 자유 요약
- **문장 수 제약**: 없음

---

## 3. 실험 목적

### 목표
본 실험의 목적은 파인튜닝이 **일반 사용자를 위한 논문 뉴스 브리핑**에
실질적인 품질 향상을 가져오는지 평가하는 것이다.

### 핵심 질문
> 비전문가 사용자가  
> 30초 안에  
> “이 논문이 무엇이고, 왜 중요한지”를 이해할 수 있는가?

---

## 4. 평가 지표 구성

### 4.1 자동 평가 지표 (게이트 지표)

- ROUGE-1 F1
- ROUGE-2 F1
- ROUGE-L F1
- BERTScore F1

> 목적: 기준 요약과의 사실적·의미적 일치 여부 확인  
> ※ 최소 기준 통과 여부 판단용

---

### 4.2 사람 평가 지표 (핵심 지표)

- 내용 충실도 (1~5)
- 유창성 (1~5)
- 간결성 (1~5)
- **일반인 이해도 (1~5)**

> 목적: 실제 사용자 관점에서의 이해 가능성 측정

---

## 8. 주요 관찰 사항

1. **모든 자동 평가 지표가 개선됨**
   - 사실성 및 의미 보존 능력 향상 확인

2. **간결성 대폭 개선**
   - 요약이 매우 압축적으로 생성됨

3. **일반인 이해도 하락**
   - 배경·해석 문장이 제거되며 맥락 부족 발생

4. **요약 구조 붕괴**
   - 2문장 설명 구조 유지 비율 감소

---

## 9. 해석 및 원인 분석

일반인 이해도 하락은 **모델 성능 저하가 아닌 요약 전략의 변화**로 해석된다.

- 파인튜닝 모델은 “정보 압축”을 우선 학습
- 설명용 문장(배경, 의미)이 제거되는 경향 확인

즉,
- ❌ 모델 품질 문제
- ⭕ 요약 포맷 및 UX 설계 문제

- 데이터 부족 ❌

## 11. 다음 액션 플랜

### 즉시 수행 (재학습 불필요)
- 요약 출력 형식 강제:
  - 정확히 2문장
  - 1문장: 연구 배경 / 문제
  - 2문장: 핵심 기여 / 중요성

### 후속 실험
- 동일 파인튜닝 모델 유지
- 프롬프트만 변경한 A/B 테스트 수행
- 일반인 이해도 재측정

## 12. 일반 사용자 뉴스 브리핑 합격 기준

| 항목 | 기준 |
|---|---|

| 내용 충실도 | ≥ 3.6 |
| 문장 수 | 정확히 2문장 |
| 사실 오류 | 0건 |

---

## 13. 최종 정리

본 실험을 통해 다음을 확인하였다.

- 파인튜닝은 요약 정확도 측면에서 성공적
- 일반 사용자 대상 요약에서는 **설명 구조가 성능을 좌우**
- 추가 학습보다 **출력 포맷 설계가 더 큰 영향**

> 일반 사용자 뉴스 브리핑의 품질은  
> 모델 크기가 아니라  
> “어떻게 말하게 했는가”로 결정된다.
